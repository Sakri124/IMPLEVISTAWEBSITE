# ImpleVista IT – Corporate Website

## Overview

The **ImpleVista IT Corporate Website** is a fully responsive business website developed using **HTML5, CSS3, Bootstrap, and JavaScript**. The site is designed to work seamlessly across desktops, tablets, and mobile devices.

It includes essential business modules such as:

* About Us
* Services
* Portfolio
* Team
* Careers
* Contact
* FAQ

The website is optimized for performance, accessibility, and modern UI/UX standards, making it suitable for real-world IT service companies.

## Key Features

* Fully responsive design (mobile-first)
* Clean and modern UI
* Multi-section corporate layout
* Contact and Career forms
* Custom domain deployment
* SEO-friendly structure

* This service allows **limited free email submissions**; additional usage may require a paid plan.

## Important Note (For Developers)

> ⚠️ **PHP Mailer is NOT active on the live deployed website.**

* PHP Mailer functionality is included **only for local or server-based execution**.
* To use PHP Mailer:

  * Download the project
  * Run it locally using **XAMPP or WAMP**
  * Configure sender credentials in:
    `mailing/mailingvariables.php`
  * Set receiver email IDs in:
    `contactme.php` and `careers.php`
  * Ensure the correct path is set for the `tmp-uploads` folder in `careers.php` for file uploads

> Note: PHP Mail functionality is not supported on static hosting platforms like Netlify.
